# Application logos

- `moondesk.svg`, `moonrobo.svg`, `moontown.svg`: existing MoonSuite Lunar
  Glyph source masters from `vectie.github.io/docs/public/logos/`. Keep their
  source geometry, palette and proportions.
- `comfyui.svg`: ComfyUI's official `comfy-logo-single.svg` from
  https://github.com/Comfy-Org/ComfyUI_frontend/blob/main/public/assets/images/comfy-logo-single.svg
  (retrieved 2026-10-15). Used to identify the separately operated application.

These are static portal branding assets. They add no application dependency or
managed-node installation.
