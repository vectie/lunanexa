# 承诺函租赁路径

## 产品要求

2026-09-16 新增并行的承诺函租赁路径，不替换传统双方合同，也不改变私有云管理员授权、IaaS 裸机、PaaS WebIDE／ComfyUI 或 MaaS 模型 API 的交付边界。

来源为用户提供的《副本6.关于实施能源谷青年人才 “创未来” 生态街区算力设备租赁方案的请示》附件 2《设备使用承诺函》。源文件全文中的请示与附件 1 不是用户需要签署的文书，不应混入生成结果。

用户选择承诺函，核对自动带入的单位及订单信息，阅读并完成使用方签署，再提交管理方审批。管理方批准替代双方对签这一准入步骤；不伪造管理方签名，不因选中模板便记录已经签署。批准后复用正常租赁准入、付款、资源预留、交付和回收能力。

产品将获批承诺函作为与传统合同并行的租赁准入依据。这是系统授权规则，不是对法律效力的独立保证。源文书原有同等效力条款应保留，版本发布仍保留部署方对具体文本的审核责任。

## 必须保留的原件内容

- 收件人为北京未来科学城产业发展有限公司；使用单位签字及盖章、签署日期。
- 账号限本企业授权人员使用，禁止违法用途、挖矿、转售、攻击、越权及违规数据。
- 书面警告、限期整改、重复违规暂停、严重违规终止，以及损害赔偿约定。
- 正常硬件故障与人为损坏的责任区分。
- 使用方自行备份，到期或终止后复位与清理的告知。
- 全额预付、固定价格、提前退租、故障退费和响应约定。

本路径复用线下商务订单：财务人员必须对当前不可变报价作出明确的全额到账确认。普通的付款凭证文件审核通过不自动代表足额到账；这也不应被宣传为支付服务商的自动清算。现有订单没有结构化起止档期，管理方确认的租期元数据必须与报价档位匹配，不能伪称已经从订单自动取得。

## 复用而非复制

承诺函使用独立、不可变的模板标识与摘要，但复用合同文档聚合、字段归属、修订栅栏、确认摘要、生成任务、编辑预览、DOCX／PDF 下载、签署证据、审批记录、事件时间线和租约消费入口。实际编辑组件的名字与支持范围以现有代码为准；不能只添加一个静态文本页面冒充 MoonEdit 集成。

租期、订单及单位资料尽量来自已存在的权威记录。不能从缺失信息中猜造公司名称、签署人、日期或金额。UI 只显示当前角色需要填写或决定的内容，后台仍保留审计及证据。

当前源码的真实编辑能力是 MoonLeaf 中立 DOCX 场景预览及 Rabbita 字段编辑。相邻 MoonEdit 项目仍是 editor-core alpha，没有可直接复用的完整 DOCX 界面及持久化宿主；本次不能将已有能力改名为 MoonEdit 或声称已经嵌入它。

## 实施状态

已完成原附件提取及四页预览、模板选择、字段编辑、签署证据提交、甲方审批、撤回修订、固定报价和明确全额到账审核的源码实现。归档元数据桥接及使用方／审核人下载授权均已接入；实际渲染、上传和同源文件传输适配器仍是运行前置条件。未部署这批修改，不应对外称为已启用。

本地 UI 定向回归及 DEMO 浏览器检查见 `UNDERTAKING_UI_ACCEPTANCE.md`；归档的跨 store 重试、下载安全边界和最长 120 秒已发授权窗口见 `CONTRACT_ARTIFACT_ARCHIVE.md`。自动测试使用合成的渲染／存储回执，不构成实际文书生成或银行到账证据。

承诺函续期必须绑定新订单，不能沿用原订单付款证据直接续期。撤权检查在后续访问及履约入口生效，已经派发资源仍走既有异步补偿／回收，不宣称跨系统原子撤销。

实施时确认现有仓库有合同 worker 的轮询与结果 API，以及 MoonLeaf 填充／校验库，但未见常驻合同渲染执行器。补齐执行器或配置已批准的外部适配器是上线前置条件，不能将本地预览结果作为归档 PDF 的替代证据。
