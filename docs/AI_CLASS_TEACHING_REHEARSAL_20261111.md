# 两小时入门课：第五轮课堂排演

本轮按老师讲述和零基础学生追问逐页修订，不把播放正常等同于学懂。
43 张内容画面各有三个具体问题：为什么需要这个概念、这一步如何得到、
它与前文有什么关系。双语开讲句、129 个问答、具体演示与停顿写在
`ai-class-rehearsal.json`，上课时通过讲稿展开，观众页继续围绕当前图示。

## 排演中改掉的跳步

- 先区分应用、模型、计算设备，再引入 Token、编号与数值表示；编号本身不表示含义。
- 给定的候选概率用于演示抽样，真实概率来自模型计算；生成结果再接入下一轮输入。
- 用购买记录计算误差和更新，再回到语言训练的真实后续概率。不会把 Token 编号当总价回归。
- 给出参数更新的算式，并回答步长如何得到；注意力组合比例与训练参数分别解释。
- 工具说明由应用提供，模型提出调用，软件执行并返回结果。预设的 if/else 也能分支，不能据此定义 Agent。
- 多 Agent 可以共用同一个模型，分开的是任务、上下文和结果交接。
- 先说明 GPU 的输入、共用参数和并行乘加，再计算权重空间，随后引入服务、集群与引擎。
- KV 缓存保留因果注意力的旧位置记录。追加 D 时仍读取 A/B/C，处理 D 后预测 E；省去重算不等于忽略前文。
- 批处理沿同一组请求、同一轮次比较；B 在两种方案中都在第四轮完成，总吞吐提高不保证每个人更快。
- 扩散先用加噪图像学习更新，再在生成时更新当前状态；蛋白质结构预测与真实折叠过程分开。
- 科学实验反馈改变候选与决策依据，不意味着每次实验都自动重新训练模型。

## 时间安排与边界

| 时间 | 内容 |
| --- | --- |
| 0–26 | 生成、表示、注意力、训练与推理 |
| 26–50 | 提示词、上下文、工具、Agent、循环与分工 |
| 50–60 | 休息 |
| 60–87 | 芯片、内存、集群、引擎、指标与 Token 工厂 |
| 87–108 | 编程、创作、科学与其他工作 |
| 108–115 | 产业分工与平台位置 |
| 115–120 | 提问 |

第一遍估算暴露了 18 个讲述过满的画面。删去重复解释，压缩过长开讲句，
为训练、缓存、批处理和去噪保留操作、观察和回答的时间。
当前用中文每分钟 210 个汉字/外语词组、英文 135 词估算口述；另以
中文 180 单位、英文 115 词模拟较慢语速。还在五处累计插入六分钟追问，
按顺序使用余量和每页明确可缩短的细节，在各主题检查点回到安排。
休息与最后提问没有被挪用。

这是作者的备课与时间预算模型，尚无真实两小时授课或学生学习效果数据。
129 个问答按需要替代对应解释，不要求额外全部朗读。完整逐页结果见
[排演记录](../output/ai-course5-20261111/TEACHING_REHEARSAL.md)。

## 目录

新增独立课程目录 `?page=ai-course-map`，五个主题覆盖全部 43 个概念。
每项列出标题、要点和时间段，支持双语关键词；“阅读”定位书页对应图，
“投屏”打开指定画面。课堂中也能检索跳转或返回当前画面。
目录从同一套讲授数据生成，防止书页、投屏与时间表分别维护后失配。

## 本轮核对的原始资料

- [Attention Is All You Need](https://arxiv.org/html/1706.03762v7)：表示、注意力与因果遮罩。
- [Transformers cache explanation](https://huggingface.co/docs/transformers/cache_explanation)：旧状态复用仍参与后续注意力。
- [Denoising Diffusion Probabilistic Models](https://arxiv.org/html/2006.11239v2)：加噪训练与反复去噪。
- [Building effective agents](https://www.anthropic.com/research/building-effective-agents)：预定义工作流与模型参与动态选择的区别。

仅使用这些资料解释原理；本轮不据此声称最新产品排名、价格或实际性能。
