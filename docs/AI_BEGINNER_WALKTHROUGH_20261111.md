# 零基础听众逐页复查

2026-11-11。本轮检查问题是：听众能否说出每步的输入、动作和结果，而非仅看到对象运动。
43 张内容页逐一重写中英文步骤说明、转场；19 章与 120 分钟安排保持不变。
下表记录原来的理解断点和对应修改。这里是作者走读，不是受试者学习效果实验。

| 页 | 原来的理解断点 | 修改后的讲法与图 |
| --- | --- | --- |
| 1 输入输出 | 编程列直接出现排序结果，易当成模型直接执行 | 区分生成程序与运行，先解释代码是计算机指令 |
| 2 应用/模型/机器 | Token、上下文、Harness、GPU、推理引擎均早于解释 | 先只讲可见软件、生成部分、执行运算的机器；移除提前出现的标签 |
| 3 Token | 分词器、词表编号、向量连续跳过 | 定义切分程序、片段、目录编号、数值列表；第四步才连编号到数值 |
| 4 上下文 | 只列内容，未解释窗口如何占用 | 定义本次全部输入；输入和后续生成共同使用窗口 |
| 5 概率 | 分布、抽样、温度无前置定义；调温后文案仍用初始值 | 用百分比与抽签解释；实际概率同步；区分抽样比例和事实正确率 |
| 6 自回归 | 只画回箭头，没说重复什么 | 把新 Token 追加为新前文，重复同一个选择过程；之后命名自回归 |
| 7 注意力 | 无上下文就给两组向量，乘加一步出现 | 给“它”相关的句子、两组已解释的数值列表；分别乘权重、逐项相加，分阶段出现 |
| 8 训练 | x/y/w、斜率、MSE同时出现；只宣布参数更新 | 用件数、单价、总价命名坐标和参数；显示每个预测与误差算式，说明偏低所以增大单价 |
| 9 训练/推理 | “用本领”比喻不能说明文件为何可用 | 对比调整参数与提供新输入；定义推理、微调、模型版本 |
| 10 训练阶段 | 预训练到后训练之间没有可读例子 | 前文/真实下一 Token、会议任务/好表格、当前任务/本次计算对应展示 |
| 11 提示词 | 工程名词只在书页结论出现 | 第一步定义 Prompt，第二步用改说明的动作定义提示词工程 |
| 12 字段提取 | 从原文直接跳到表格 | 逐句指出事项/负责人/日期，逐列对应，缺少的格保留未提及 |
| 13 上下文工程 | 调用、状态、工具结果混用 | 先解释一次调用，再分别选择任务、历史、资料，最后组装 |
| 14 RAG | 英文缩写先于操作含义 | 先解释检索是找段落，区分找到原文与生成答案，再解释缩写 |
| 15 工具调用 | 调用代码与执行动作容易混淆 | 定义工具，翻译 city/day 参数，单独讲程序查询、结果返回 |
| 16 Agent | 步骤名“决定/行动”与实际出现内容不一致 | 改为目标、天气返回、选择下一步、执行继续；定义 Harness 与 Agent，工具名用中文动作 |
| 17 工作流 | 固定/动态只有抽象分类 | 同一录音顺序与读结果再选工具对比；说明可以组合 |
| 18 反馈循环 | 默认排序为何错、比较函数做什么未解释 | 按首字符1/2/3说明文字顺序；数值比较是改规则，无需会读语法 |
| 19 三个循环 | 多个层级名词没有明确变化对象 | 逐一指出当前程序、未来助手工具、内部参数三个被改对象；由反馈去向解释循环工程 |
| 20 RSI | 缩写及“递归”没有展开 | 展开英文/中文含义，用版本链讲新工具如何回到自身改进过程 |
| 21 多 Agent | 工作者可能被理解为不同大模型 | 定义独立助手和独立输入；同模型可多次运行；说明 Agent swarm |
| 22 串并行 | 只有总时间，未定义串并行 | 先定义依次做/同时做，分开日历等待和总工作量 |
| 23 GPU | 矩阵、HBM、点积堆在一张图 | 先定义处理器/显存/带宽；用两行独立乘加解释并行；移除 HBM、点积标签 |
| 24 存储算术 | bit、字节、FP16、量化、KV 同时出现 | 先给单位关系；FP16变为2字节乘法；定义量化和缓存后才引出 KV |
| 25 集群/引擎 | 节点、实例、Pod、Prefill、Decode、KV 连续跳步 | 逐步定义机器/节点、运行一份服务、引擎；缓存保留A/B/C、追加D依次出现 |
| 26 并行/副本 | 图只有半模型、整模型英文 | 解释一份模型合作和完整复制；用不同用户请求说明用途 |
| 27 延迟 | 名字和计时范围没绑定 | 从发送到首字、首字到完成逐步计时；定义 TTFT 和端到端 |
| 28 间隔 | 直接要求相信101个点有100个间隔 | 先画3点2间隔；解释毫秒；两种速率均保留除法和计时边界 |
| 29 吞吐/批处理 | 槽位、A1、轮次没解释；7轮动画一闪而过 | 定义槽位和格子；突出第3轮空位；逐轮动画延长到8.4秒，保留单轮按钮；给条件相同的吞吐算例 |
| 30 工厂 | 机架与节点只是术语堆叠 | 由耗电发热解释设施，逐层到机器、集群、模型服务，最后解释工厂比喻 |
| 31 手机请求 | 模型与机器容易被理解为两个生成模型 | 区分服务中的模型版本与执行它的引擎/设备，说明去程与回程 |
| 32 AI编程 | 重复排序代码却没讲生成/执行差别 | 接回开场目标，区分语言生成规则与普通程序执行 |
| 33 编程助手 | 泳道中edit/run与工具含义不明 | 定义编辑器、终端；逐步指出谁提出、谁写入、谁运行、谁带回结果 |
| 34 扩散 | 中间咖啡店图像暗示原图藏在噪声里 | 定义随机噪声、文字条件；用单格0.60−0.20=0.40演示状态更新；中间用数值格，最终才解码为图像 |
| 35 AIGC | AIGC、多模态藏在结论/补充说明 | 在当前步骤解释缩写；按剧本、时间序列、音轨、剪辑串联 |
| 36 AI4S | 氨基酸/结构没解释；多条曲线像多蛋白质 | 定义字母序列与链；改为单条连续结构曲线，区分结构展示与真实折叠过程 |
| 37 科学搜索 | 纵轴性质不具象，挑F/G依据不清 | 以耐热指标、越高越好定义任务和坐标；预测/观察分别标识，再回到选点 |
| 38 会议应用 | 转录/提取/写入的责任混在一起 | 按声音、文字、字段表、任务系统拆解；说明相对日期还需明确后才能写日历 |
| 39 其他AI | 预测图缺坐标、路线图缺图例 | 解释横轴时间/纵轴需求；障碍、起终点、动作顺序可对应 |
| 40 产业 | API此前没有正式解释；模型开发和服务混为一谈 | 定义程序调用接口，分别指出训练团队和服务运营的动作 |
| 41 API/自运行 | 接口/权重/开源之间跳步 | 沿请求和结果讲两条交付路径，再解释权重可获取与发布许可 |
| 42 平台 | 又堆一遍路由名词，没接回前面 | 用已学的任务组织、服务资源、实际执行定位平台，细节留后续课 |
| 43 总图 | 模型→GPU→结果像先模型算完再进GPU | 硬件改为执行支撑关系；结果从模型返回应用再到表格，回收同一个会议任务 |

## 跨页播放修正

“播放这一步”仅播放当前步骤；完成后停在结果和说明，不再每约2秒自动跳下一步。
手动下一步、重来、暂停与继续保留；未讲到的阶段完全隐藏，避免先读到未来术语。
注意力、训练、缓存、批处理按计算过程使用不同的时长，均为有限帧动画。
