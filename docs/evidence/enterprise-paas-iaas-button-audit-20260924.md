## 本轮修正

- 按 IaaS 企业机器、PaaS 个人应用、MaaS 企业模型重组入口和交付面板；空库存不再出现可选的重复 SKU。
- 个人 MoonDesk 不显示无意义的单选模型来源或空的专属交付表单；ComfyUI 的独占授权前置条件及下一步可见。
- 自助订单不再向普通用户展示 API 路径、租户标头和内部集成契约；登录条不再暴露原始 subject/organization ID。
- IaaS 交付文案改为独占 GPU 算力及订单约定的访问方式；账户页将技术标识和有效会话折叠，过滤过期／撤销会话，并修正过时的身份说明。
