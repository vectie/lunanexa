# 承诺函整机下发加固与现场核验（2026-09-27）

## 本轮修复

- 承诺函整机分配只接受节点代理心跳中标注的 `enterprise-dedicated` 资源池；`.176/.177` 试用池不能被下发，即使将来释放内存也一样。
- 企业承诺函的整机预留由有效订单、签署执行证据与租期维持，不再错误地依赖购买人个人 WebIDE 租约；其他企业成员仍须取得自己的 Developer 工作区授权才能启动应用。
- 普通个人资源预留按精确租约和授权 ID 校验，避免同一用户存在多张租约时误用第一张租约而提前回收。
- 管理端区分订单关闭、订单到期、租期不可用；节点选择显示资源池错误或内存不足的具体原因。节点总览在宿主可用内存低于 32 GiB 时不再显示“可进入预检”。
